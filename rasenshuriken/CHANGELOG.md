# Changelog

## [Unreleased]

## [0.2.0] - 2026-11-22

### Added
- Light mode ("day sky") with deeper blues that still fade by stage.
- `modo` option (`auto`, `claro`, `oscuro`) in the plugin's config menu.

### Changed
- Message, tool-row and heading colors follow the light or dark mode.
- The row above the prompt uses a mid tone that reads on light and dark terminals.

## [0.1.0] - 2026-11-22

### Added
- Five stages tied to the context window, from Rasenshuriken to an incomplete Rasengan.
- Animated backdrop, dark palette, row above the prompt, status line entry, stage toasts and `/chakra`.
